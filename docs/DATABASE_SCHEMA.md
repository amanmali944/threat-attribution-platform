# PostgreSQL Database Schema v1.0

## Entity Relationship Topology

The backend utilizes PostgreSQL with JSONB capabilities for flexible telemetry payloads and threat attribution metadata. Multi-tenancy is enforced via `tenant_id` indexing across all entity tables.

```
+------------------+         +--------------------+         +-------------------+
|      events      |         |     entities       |         |      alerts       |
+------------------+         +--------------------+         +-------------------+
| id (PK)          |         | id (PK)            |         | id (PK)           |
| tenant_id (IX)   |         | tenant_id (IX)     |         | tenant_id (IX)    |
| source_layer     |         | entity_type        |         | title             |
| event_type       |         | identifier         |         | description       |
| observed_at (IX) |         | properties (JSONB) |         | severity          |
| payload (JSONB)  |         | first_seen         |         | status            |
| severity         |         | last_seen          |         | rule_id           |
| created_at       |         +--------------------+         | observed_at (IX)  |
+------------------+                                        | created_at        |
         ^                                                  +-------------------+
         |                                                            ^
         +------------------- event_alerts (M2M) ---------------------+
                                                                      |
                                                          incident_alerts (M2M)
                                                                      |
+------------------+         +--------------------+         v-------------------+
|   attributions   |         |     audit_logs     |         |     incidents     |
+------------------+         +--------------------+         +-------------------+
| id (PK)          |         | id (PK)            |         | id (PK)           |
| tenant_id (IX)   |         | tenant_id (IX)     |         | tenant_id (IX)    |
| incident_id (FK) |----->   | user_id (FK)       |         | title             |
| actor_name       |         | action             |         | description       |
| campaign         |         | resource           |         | severity          |
| confidence_score |         | details (JSONB)    |         | status            |
| tactics_tech     |         | created_at (IX)    |         | assigned_to       |
| created_at (IX)  |         +--------------------+         | created_at (IX)   |
+------------------+                                        | updated_at        |
                                                            +-------------------+
```

## Data Dictionary & Index Strategy

### 1. `events` Table
Stores raw normalized telemetry events.
- `id` (VARCHAR(64), Primary Key)
- `tenant_id` (VARCHAR(64), NOT NULL, **INDEXED**)
- `source_layer` (VARCHAR(32), NOT NULL)
- `event_type` (VARCHAR(64), NOT NULL)
- `observed_at` (TIMESTAMP WITH TIME ZONE, NOT NULL, **INDEXED**)
- `payload` (JSONB, NOT NULL)
- `severity` (VARCHAR(16), NOT NULL)
- `created_at` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW())

**Indexes:**
- `ix_events_tenant_id` (`tenant_id`)
- `ix_events_observed_at` (`observed_at`)
- `ix_events_tenant_observed` (`tenant_id`, `observed_at` DESC)

---

### 2. `entities` Table
Tracked infrastructure & identity objects (Hosts, IPs, Users, Hashes).
- `id` (VARCHAR(64), Primary Key)
- `tenant_id` (VARCHAR(64), NOT NULL, **INDEXED**)
- `entity_type` (VARCHAR(32), NOT NULL)
- `identifier` (VARCHAR(255), NOT NULL)
- `properties` (JSONB, DEFAULT '{}')
- `first_seen` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW())
- `last_seen` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW())

**Indexes:**
- `ix_entities_tenant_id` (`tenant_id`)
- `ix_entities_tenant_identifier` (`tenant_id`, `identifier`)

---

### 3. `alerts` Table
Detections generated by analytical or rule-based models.
- `id` (VARCHAR(64), Primary Key)
- `tenant_id` (VARCHAR(64), NOT NULL, **INDEXED**)
- `rule_id` (VARCHAR(64), NOT NULL)
- `title` (VARCHAR(255), NOT NULL)
- `description` (TEXT)
- `severity` (VARCHAR(16), NOT NULL)
- `status` (VARCHAR(32), DEFAULT 'open')
- `observed_at` (TIMESTAMP WITH TIME ZONE, NOT NULL, **INDEXED**)
- `created_at` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW())

**Indexes:**
- `ix_alerts_tenant_id` (`tenant_id`)
- `ix_alerts_observed_at` (`observed_at`)
- `ix_alerts_tenant_status` (`tenant_id`, `status`)

---

### 4. `incidents` Table
Higher-order security incidents clustering multiple alerts.
- `id` (VARCHAR(64), Primary Key)
- `tenant_id` (VARCHAR(64), NOT NULL, **INDEXED**)
- `title` (VARCHAR(255), NOT NULL)
- `description` (TEXT)
- `severity` (VARCHAR(16), NOT NULL)
- `status` (VARCHAR(32), DEFAULT 'open')
- `assigned_to` (VARCHAR(128))
- `created_at` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW(), **INDEXED**)
- `updated_at` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW())

**Indexes:**
- `ix_incidents_tenant_id` (`tenant_id`)
- `ix_incidents_created_at` (`created_at`)

---

### 5. `attributions` Table
Threat intelligence & actor correlation for incidents.
- `id` (VARCHAR(64), Primary Key)
- `tenant_id` (VARCHAR(64), NOT NULL, **INDEXED**)
- `incident_id` (VARCHAR(64), FK -> `incidents.id`, NOT NULL)
- `actor_name` (VARCHAR(128), NOT NULL)
- `campaign` (VARCHAR(128))
- `confidence_score` (FLOAT, NOT NULL)
- `tactics_techniques` (JSONB, DEFAULT '[]')
- `created_at` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW(), **INDEXED**)

**Indexes:**
- `ix_attributions_tenant_id` (`tenant_id`)
- `ix_attributions_incident_id` (`incident_id`)

---

### 6. `users` Table
Platform operator users.
- `id` (VARCHAR(64), Primary Key)
- `tenant_id` (VARCHAR(64), NOT NULL, **INDEXED**)
- `username` (VARCHAR(64), NOT NULL, UNIQUE)
- `email` (VARCHAR(255), NOT NULL, UNIQUE)
- `hashed_password` (VARCHAR(255), NOT NULL)
- `role` (VARCHAR(32), DEFAULT 'analyst')
- `is_active` (BOOLEAN, DEFAULT TRUE)
- `created_at` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW())

---

### 7. `audit_logs` Table
Security audit trails.
- `id` (VARCHAR(64), Primary Key)
- `tenant_id` (VARCHAR(64), NOT NULL, **INDEXED**)
- `user_id` (VARCHAR(64), FK -> `users.id`, NULLABLE)
- `action` (VARCHAR(64), NOT NULL)
- `resource` (VARCHAR(128), NOT NULL)
- `details` (JSONB, DEFAULT '{}')
- `created_at` (TIMESTAMP WITH TIME ZONE, DEFAULT NOW(), **INDEXED**)

**Indexes:**
- `ix_audit_logs_tenant_id` (`tenant_id`)
- `ix_audit_logs_created_at` (`created_at`)
