# API Contract v1.0

## Overview

Base URL: `/api/v1`

All responses follow a standard JSON envelope or collection format. Standard status codes:
- `200 OK`: Successful retrieval or action
- `201 Created`: Resource successfully created
- `400 Bad Request`: Validation error in payload or query params
- `404 Not Found`: Resource not found
- `500 Internal Error`: Server execution failure

---

## 1. Events API

### `POST /api/v1/events`
Ingest a single canonical event or batch of canonical events.

**Request Body:**
```json
{
  "event_id": "evt-1001",
  "tenant_id": "tenant-01",
  "source_layer": "endpoint",
  "event_type": "process_execution",
  "observed_at": "2026-10-05T10:00:00Z",
  "severity": "medium",
  "payload": {
    "process_name": "powershell.exe",
    "command_line": "powershell -e AAAA..."
  },
  "metadata": {}
}
```

**Response (201 Created):**
```json
{
  "id": "evt-1001",
  "status": "ingested",
  "created_at": "2026-10-05T10:00:01Z"
}
```

### `GET /api/v1/events`
Query events with optional filters.

**Query Parameters:**
- `tenant_id` (string, required)
- `source_layer` (string, optional)
- `event_type` (string, optional)
- `start_time` (datetime ISO8601, optional)
- `end_time` (datetime ISO8601, optional)
- `limit` (int, default 50)
- `offset` (int, default 0)

**Response (200 OK):**
```json
{
  "total": 1,
  "limit": 50,
  "offset": 0,
  "items": [
    {
      "id": "evt-1001",
      "tenant_id": "tenant-01",
      "source_layer": "endpoint",
      "event_type": "process_execution",
      "observed_at": "2026-10-05T10:00:00Z",
      "severity": "medium",
      "payload": {
        "process_name": "powershell.exe"
      },
      "created_at": "2026-10-05T10:00:01Z"
    }
  ]
}
```

### `GET /api/v1/alerts`
List alerts for a tenant with optional filtering by detector and technique.

**Query Parameters:**
- `tenant_id` (string, required)
- `detector` (string, optional)
- `rule_id` (string, optional)
- `technique` (string, optional)
- `severity` (string, optional)
- `status` (string, optional)
- `limit` (int, default 50)
- `offset` (int, default 0)

## 3. Incidents API

### `POST /api/v1/incidents`
Create a correlated multi-stage incident (extended per CR-04).

**Request Body:**
```json
{
  "tenant_id": "tenant-01",
  "title": "Lateral Movement & C2 Activity Detected",
  "description": "Correlated alerts across workstation-01 and domain controller",
  "severity": "critical",
  "status": "investigating",

  "risk_score": 91.4,
  "risk_level": "critical",

  "first_seen": "2026-10-05T10:15:02Z",
  "last_seen": "2026-10-05T10:26:13Z"
}
```

**Response (201 Created):**
```json
{
  "id": "inc-9001",
  "tenant_id": "tenant-01",
  "title": "Lateral Movement & C2 Activity Detected",
  "description": "Correlated alerts across workstation-01 and domain controller",
  "severity": "critical",
  "status": "investigating",
  "assigned_to": "analyst@corp.com",
  "risk_score": 91.4,
  "risk_level": "critical",
  "layers": ["identity", "application", "database"],
```

## 5. Graph API

### `GET /api/v1/graph`
Retrieve correlated entity & alert relationship topology graph for visual representation.

**Query Parameters:**
- `tenant_id` (string, required)
- `incident_id` (string, optional)

**Response (200 OK):**
```json
{
  "nodes": [
    {
      "id": "ent-1",
      "label": "workstation-01",
      "type": "host",
      "properties": {"ip": "10.0.1.15"}
    },
    {
      "id": "ent-2",
      "label": "user_admin",
      "type": "user",
      "properties": {"domain": "CORP"}
    }
  ],
  "edges": [
    {
      "source": "ent-2",
      "target": "ent-1",
      "relation": "LOGGED_INTO",
      "weight": 1.0
    }
  ]
}
```
